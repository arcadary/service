# Arcadary service

The remote service for [Arcadary](https://github.com/bk-one/arcadary): catalog updates, compatibility records and controller profiles for the launcher. It is an empty Rails 8.1 application for now; nothing is built or deployed.

```bash
bin/setup --skip-server
bin/dev
bin/ci
```

What it is for, the rules and the setup are in [AGENTS.md](AGENTS.md).
